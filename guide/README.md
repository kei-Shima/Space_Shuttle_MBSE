# MBSE 初心者ガイド

スペースシャトルの設計モデルを教材に、MBSE（モデルに基づくシステムズエンジニアリング）を「何から、どの順で見るか」を案内する付属ガイドです。

- ブラウザで読む：<https://kei-shima.github.io/Space_Shuttle_MBSE/guide/>（図入りの HTML 版。GitHub の画面では HTML はソース表示になるため、こちらで読んでください）
- 所要：合計およそ 3 時間

## 学習の順序

| ステップ | やること | 最初に開くもの | 目安 |
|---|---|---|---|
| 0 言葉 | 略語・用語を引けるようにする | [略語表](../docs/SSD-ACR-SYS-001.md) | 10分 |
| 1 全体 | システムと構造を図で見る | 図1・図2・図89 | 30分 |
| 2 要求 | 要求の一覧と値の書き方 | 図90、[SSD-RQM-SYS-001](../docs/SSD-RQM-SYS-001.md) | 30分 |
| 3 振る舞い | 使われ方・状態・時間の流れ | 図93・図76・図84 | 45分 |
| 4 検証と追跡 | 要求 → 検証の線をたどる | 図110・図115 | 45分 |
| 5 SysML と演習 | 実物のテキストを読む | [SysML/](../SysML/SSD-RQF-SYS-001.sysml) | 60分 |
