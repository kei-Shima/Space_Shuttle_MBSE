5　演習

答えは、折りたたみの中に出典つきで書いてあります。先に自分で探してから開いてください。

演習1　要求の値を読む

REQ-SYS-01 は、何を何個と定めていますか。SSD-RQF-SYS-001.sysml から探します。

答えと確かめ方

主要素 4、SRB 2 本、SSME 3 基。SysML を読むの例1（SSD-RQF-SYS-001.sysml の 12〜21 行目）に書かれています。

演習2　要求から検証ケースへ

REQ-SYS-02（軌道高度）は、どの方法で確かめることになっていますか。SSD-VER-SYS-001.sysml の VC-REQ-SYS-02 を探します。

答えと確かめ方

実証（Demonstration、demo）です。VC-REQ-SYS-02 の @VerificationMethod に kind = VerificationMethodKind::demo と書かれています。値の範囲は、RQF の REQ-SYS-02 に 100〜312 n.mi. とあります。

演習3　追跡の規模をつかむ

SSD-TRC-SYS-001.sysml の先頭近くに、追跡の種類ごとの件数が書かれています。「満たす（satisfy）」と「検証（verify）」は、それぞれ何件ですか。

答えと確かめ方

TR-02（satisfy）が 3206 件、TR-03（verify）が 1352 件です（SSD-TRC-SYS-001.sysml の 15〜16 行目の count）。件数は、版を重ねると変わることがあります。ファイルの現在の値を見てください。

演習4　図とテキストを見比べる

図76の状態遷移図と、SSD-BEH-ORB-001.sysml の state def MissionMode を見比べ、図の矢印が transition のどの行に対応するかを 1 本見つけてください。

ヒント

PH-2a（上昇・第1段）から PH-2b（第2段）への矢印は、transition TR_02 first PH_2a accept SrbSeparation then PH_2b; に当たります（SRB 分離の事象で切り替わる）。

演習5　自分で 1 本たどる（まとめ）

  1. 図90から、気になる要求を 1 つ選ぶ。
  2. SSD-RQM-SYS-001 で文面と出典を読む。
  3. SSD-VER-SYS-001 で、その検証ケースの方法を確かめる。
  4. 図115の追跡の鎖の中で、その線がどこに当たるかを見る。

ここまでできれば、MBSE の核心（要求から検証までを線でたどる）を一通り体験したことになります。次は、気になる系（電源、環境制御、誘導など）を文書一覧から選んで、同じ手順を繰り返してください。
