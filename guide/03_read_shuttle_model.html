3　このパッケージの歩き方

図 → 説明書 → SysML の順に、上から開いてください。

読み方のコツ：1 枚の図を完全に理解しようとしないでください。最初は「箱と線で何を言っているか」だけを見ます。細かい数値や略称は、あとで説明書と略語表で確かめます。

ステップ0　言葉をそろえる

ここでわかること：略称の意味を引けるようになる。
順開くもの見どころ
1略語表 SSD-ACR-SYS-001知らない略称はここで引く。ブックマーク推奨
2用語の早見表MBSE の用語を 1 行ずつ

ステップ1　全体と構造

ここでわかること：システムが何でできているかを説明できる。
順開くもの見どころ
1図1　システム構成いちばん外側の構成。何を設計しているか
2図2　オービタ サブシステム構成中心となる機体の内訳
3図89　システム構成（BDD）部品の種類と包含。箱の入れ子を見る
4図92　モデルの構成（パッケージ図）モデルをどうまとめているか（パッケージ）
5SSD-MDL-SYS-001モデルの統合と検査の説明書

ステップ2　要求

ここでわかること：「要求」が何で、どんな形で書かれているかを言える。
順開くもの見どころ
1図90　要求の導出・充足 行列要求がどこから導かれ、何で満たされるか
2SSD-RQM-SYS-001要求モデルの説明書（導出・充足・検証方法）
3SSD-RQF-SYS-001要求を属性・制約・値で表した版（形式化）。SysML を読むで扱います

ステップ3　振る舞い

ここでわかること：使われ方・状態・時間の流れの 3 つの見方を区別できる。
順開くもの見どころ
1図93　運用のユースケース誰が何のために使うか
2図76　ミッションフェーズ・アボート 状態遷移フェーズが切り替わる条件
3図84　上昇 シーケンス時間順のやり取り
4SSD-UC-ORB-001運用シナリオ・ユースケースの説明書
5SSD-BEH-ORB-001状態遷移の説明書

ステップ4　内部のつながり

ここでわかること：部品の内側で何が何につながるかを読める。
順開くもの見どころ
1図112　EPS 発電・配電 内部ブロック図線をたどり、流れるものを追う
2SSD-IBD-ORB-001機器の接続と流れる物の説明書

ステップ5　検証と追跡

ここでわかること：要求 → 検証の線をたどれる。
順開くもの見どころ
1図110　検証マトリクス要求ごとの検証方法の行列
2図115　トレースの連鎖要求から検証まで、線でつながる様子
3図116　系ごとのトレース網羅系ごとに、つながりが揃っているかの集計
4SSD-VER-SYS-001検証ケース・検証マトリクスの説明書
5SSD-TRC-SYS-001トレース網羅・影響分析の説明書

図書一覧の使い方

さらに先へ進むときは、図書一覧を使います。図面のページは、見る立場（ビューポイント）ごとに縮小図が並びます。系（電源、環境制御、誘導など）ごとの説明書は、文書一覧から選べます。

GitHub の画面で読むときは、docs/SSD-SYS-IDX-001.md から Markdown の説明書をたどれます。
