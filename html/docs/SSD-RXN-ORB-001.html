1. 目的

燃料電池が飛行全体で使った酸素・水素と、同じ期間の発電量（kWh）を、飛行ごとの記録と、1 kWh あたりの量・質量比の表（制約への束ね）として持つ。これまでのモデルには、標準ミッションの設計値（SSD-PAR-ORB-001 の ReactantBudget。1 kWh あたり酸素 0.7・水素 0.09 lbm）と少数の飛行の残量（SSD-PRF-ORB-001 の PFP）はあったが、飛行ごとの消費の実績は無かった。本書は Mission Report 本文の値を、飛行ごとの表・束ねの表・年代ごとの表（図309〜311・315）にする。**判定は付けない**：設計値との差は数で示すだけ。

2. 範囲と書き方

記録は Mission Report 本文に、燃料電池の酸素・水素の量と発電量が同じ文または続く1文に書かれたものだけで、108飛行。そのうち判断に迷う 17飛行は境界として数えず（表には理由つきで載せた）、図・集計は数える 91飛行（1 kWh あたりの酸素 0.673〜0.720、水素 0.0833〜0.0890 lbm）。値は本文のまま（lbm・kWh）。1 kWh あたりの量・質量比・水と（酸素＋水素）の差は本書の計算で、本文の値ではない。水の量は報告書が酸素と水素から出す値で、独立な測定の照合ではない（注記）。
