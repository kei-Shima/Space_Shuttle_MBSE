1. 目的

EVAの各機能に関係する公開文書を機能別に整理し、各機能説明書と図61 EVA 関連文書マトリクス（文書×機能マトリクス）の根拠とする。

2. 調査方法

乗員運用マニュアル（SCOM、OI-33）・運用飛行規則・故障処置手順・IOA の FMEA/CIL 評価などの公開文書を調べ、EVAの機能に関係する記述の頁を確かめた 14件を載せた（出典欄はすべて「新規」）。各文書の番号・表題・確認に使った URL は表の各行に、記述の頁は各欄の出典に示す。
