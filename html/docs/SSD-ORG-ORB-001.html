1. 目的

打上げと飛行の可否は、機器の設計だけでなく、誰が（組織）、どの審査・会議で（ゲート）、何を根拠に（基準・情報）決めたかで決まる。これまでのモデルには、MMT・FRR・CoFR の語は事象や記述の中に出ていたが、組織・責任・認証のゲート・当時の判断を記録としてモデルに持つ文書は無かった。本書は Rogers 報告（1986）・CAIB 報告（2003）・RTF Task Group（2005）・勧告の実施（1987）・FRR 資料の本文から、プログラム組織、認証のゲート、STS-51L と STS-107 の当時の判断の事例を記録にし、MOD（運用局）の CoFR の状況を表にする。

2. 範囲と書き方

組織 79件・ゲート 50件・判断の事例 51件は、資料の本文の文に書かれたものだけで、推定していない。判断の事例は当時その場で下された判断に限り、委員会の所見・後からの評価は入れていない。時点は「資料の年」（報告書が出た年）と「本文の年」（記録が当てはまると本文が書く年。書かれていなければ空欄）を分け、時点の違う組織を1つにまとめていない。CoFR の表は STVD の FRR 資料の 3表で、MOD の部門ごとの状況であり、プログラム全体の CoFR ではない。
