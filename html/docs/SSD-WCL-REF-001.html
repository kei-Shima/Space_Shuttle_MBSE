1. 目的

水冷却ループ（WCL）の各下位機能に関係する公開文書を機能別に整理し、各機能説明書と図37 水冷却ループ 関連文書マトリクス（文書×機能マトリクス）の根拠とする。

2. 調査方法

SSD-ARS-REF-001の3.8節 水冷却ループ（WCL）の14件を引き継ぎ（出典欄「ARS-REF（AR-01）」の形）、今回の調査で6件を追加した（出典欄「新規」）。引き継いだ行も含め、各行の関連内容は下位機能ごとに書き分けた。訓練マニュアル（USA006020・USA006019）、SCOM、運用飛行規則、故障処置手順（MAL）、飛行運用マニュアル（JSC-12770）、SODB、Orbit Opsチェックリスト、IOA、ミッション報告（STS-2・108・114）は原本で本文を確認し、関連内容に節とPDFの通し頁を示す。News Reference ManualはWebページの本文で確認した。頁を示していない行（NTRSの報告書・抄録、STS-107報告、Space Shuttle Guide）は、SSD-ARS-REF-001に記した内容を下位機能に割り振った。
