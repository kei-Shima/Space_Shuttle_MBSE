1. 目的

上位の IF（システム間の IF-SYS-01〜10 と、オービタの系どうし・外部要素の IF-ORB-01〜49）のそれぞれに、インタフェース要求を1件ずつ定める。要求は IF 特性表（SSD-ICD-ORB-001：流れるもの・特性値・冗長・フェーズ）から起こし、上位の要求（L1：SSD-REQ-SYS-001、L2：SSD-REQ-<系>-001）から導出し、IF を割付先にし、検証の根拠（飛行・試験の記録）を付ける。これまで要求は主に機能行に割り付けていて、IF を割付先にした要求は 589件のうち 39件だった。

2. 書き方

要求の ID は IF の番号に合わせる（IF-ORB-05 → IRQ-ORB-05）。要求文は「送り側は受け側へ、流れるものを、特性値・条件で供給する（伝える・支える）こと」の形で、値と単位は IF 特性表と資料のまま書いた。上位は、その IF が支える既存の要求である。検証方法は A（解析）・T（試験）・I（検査）・D（実証）、検証の状態は、検証方法に合う一次資料の記録があるものを「根拠あり」、見つからなかったものを「根拠なし」（理由つき）とした。設計の記述をなぞるだけの文は根拠にしていない。
