1. 目的

故障解析表（SSD-FMEA-<系>-001 の CIL 課題の評価ワークシート 889件と SSD-FMEA-ORB-001 §5 の PRSD の CIL 項目 20件、計 909件）の行を、SysML v2 の故障モード（FailureMode の occurrence）にし、関わる機能ブロック、ハザードの原因（SSD-HAZ-ORB-001）、検知する警報（SSD-FDIR-ORB-001）、原因に当たる管理策までを1つの因果の連鎖にする。下からの解析（故障解析表）と上からの解析（ハザード解析）を故障モードでつなぎ、検知の無い故障モード・故障モードの無い原因・管理策の無い原因を網羅の表で示す。全体は図126・127 に示す。

2. 書き方

故障モードの ID・品目・重要度は故障解析表の行のまま（重要度は NASA／IOA、同じときは1つ）。関わる機能ブロックは行の機能・IF の欄から引いた（機能行は所有の機能説明書、IF は端の機能説明書）。原因・警報への対応は、関わる機能ブロックまたはその上位の機能ブロックが、原因の機能説明書・警報の監視する機能説明書に含まれるかの規則による本書の対応づけで、故障モードごとに確かめたものではない。管理策とハザードは原因から引いた。

注記　ECLSS の故障モード 38件の第3段・第4段への対応と、PCS・給水廃水・WCS・FDS・ALS の機能の故障モードは SSD-FMX-ECL-001 に示す（SysML v2 テキスト：SysML/SSD-FMX-ECL-001.sysml）。
