1. 目的

本書の TPM は、運用の飛行ごとの実測値（Mission Report の表・本文の値）を、要求・飛行規則の閾値と比べた推移である（本書の判断）。開発の間に設計の現在の見込み値を閾値と比べて追う、システムズエンジニアリングの TPM ではない（その推移は公開資料からほぼ取れない）。本書は、既存の要求（SSD-REQ-SYS-001 の L1・系の要求書の L2）から、飛行ごとの成否を表す MOE、系の性能を表す MOP、閾値を持つ量 TPM を引き、STS-27 以降の Mission Report 86飛行（打上げ 1988-12-02 〜 2011-07-08）の値を載せる。指標を新しく作らない。値を載せられない MOE は、下位の判定のまとめだけを書く。

2. 書き方

値は Mission Report の表または本文の転記で、換算・補間・推定をしない（日数・高度の読み取りは本書の計算）。横軸は打上げの日付（UTC。STS の番号は打上げ順ではない）。各飛行の根拠の欄に、引いた頁の文と URL を示す。判定は、閾値の出どころの資料の年以降の飛行だけで行い（判定の窓。REQ-SYS-17・REQ-APU-01 は SCOM 2008 → 2008年以降、A4-108 は飛行規則 2002年版 → 2002年以降）、それより前の飛行は「後の時代の基準に照らした参考」として分けた。要求が「できること」の範囲（REQ-SYS-02・REQ-SYS-06）の量は、範囲の外の実績を外れとは呼ばず、能力の実証の範囲の外として数えた。
