## 1. 目的

関係者の期待に対して、実際に飛んだシステムの実績で「期待を満たしたか」を判定する（妥当性確認）。これまでのモデルは、要求を満たすか（検証、SSD-VER-SYS-001）と、測定指標の実績（SSD-TPM-SYS-001）までで、要求になる前の関係者の期待を満たしたかを判定した記録は無かった。本書は NASA SP-4221 が述べる定量の期待を取り、飛行の記録に当てた。

## 2. 検証との違い

検証は「要求の値を満たすか」を、検証の方法（検査・解析・試験・実績）で判定する（SSD-VER-SYS-001）。妥当性確認は「運用の期待を満たしたか」を、実際に飛んだ実績で判定する。貨物の質量・ベイの寸法・クロスレンジのように、そのまま L1 要求になった期待を判定し直すと検証と同じ問いになるので、本書では判定せず、「期待→L1 要求→検証の判定」の対応だけを示した。妥当性確認のケースにしたのは、飛行の頻度・費用・ターンアラウンド・再使用の回数など、運用の結果を問う期待である。

## 3. 範囲と書き方

期待は NASA SP-4221（歴史書・二次資料。1972年までの記述）の本文が述べる定量の期待 28件（想定・売り込みの数字を含み、約束された期待と区別して注記に書いた）。実績は 1981〜2011 年の飛行（132飛行。報告書の無い STS-51L・STS-61A・STS-79 を除く）で、期待の年（1963〜1972）とずれがある。判定は満たした・一部・満たさなかった・確認できない。記録が無い、または全体として言えないものは「確認できない」にし、推定しない。

## 12. 注記（出典間の相違・構成変更）

> **注記** 範囲・取れなかった値・本書の判断：期待は NASA SP-4221（歴史書・二次資料。1972年までの記述）の本文が述べる定量の期待 28件（担当は全文を読み切っていない。見落としがありうる）。計画の売り込みの数字（想定）が多く、約束された期待と区別して note に書いた。実績は 1981〜2011 年の飛行で、期待の年（1963〜1972）と実績の期間にずれがある。

> **注記** 範囲・取れなかった値・本書の判断：期待を2つに分けた（本書の判断）：貨物の質量・ベイの寸法・クロスレンジ・乗員数のように、そのまま L1 要求（REQ-SYS）になった期待は、妥当性確認で判定し直さない（判定すると要求の値を満たしたかを問う検証と同じになるため）。「期待→L1 要求→検証の判定」の対応だけを示した。妥当性確認のケースにしたのは、運用の結果を問う期待（飛行の頻度・費用・ターンアラウンド・再使用の回数など）。

> **注記** 範囲・取れなかった値・本書の判断：判定は「満たした／一部／満たさなかった／確認できない」。飛行の頻度は、数えられていない飛行（打上げ日の無い飛行・報告書の無い飛行）を足した上限で判定し、その上限でも期待に届かないときだけ「満たさなかった」とした。費用・エンジンの寿命・ターンアラウンドは記録が無い、または全体の最短と言えないので「確認できない」にした（推定しない）。

> **注記** 範囲・取れなかった値・本書の判断：事前の基準 (b)「判定が満たした・一部・満たさなかったのケース 5件以上」は、飛行の頻度の期待 4件だけで 5件に届かなかった（結果を見たあと、ユーザーに数字を示して選んでもらい、基準を「判定が付いたケース 4件以上」に直して進めた。結果を見たあとの変更であり、事前の基準ではない。「確認できない」の期待は理由つきで残し、数に入れない）。

> **注記** 範囲・取れなかった値・本書の判断：オービタと着陸日は Mission Report 本文の文による（132飛行。報告書の無い 3飛行を除く）。着陸日は本文に暦日の文が無く GMT の通日だけの飛行と、日付が本文内で矛盾する飛行、着陸しなかった STS-107 は日付なしとし、計算した日付を使っていない。
