## 1. 目的

このパッケージの文書・図・SysML に出る英語の略称について、正式名称（英語）・日本語名・分類・出典を一覧にする。これまでは、略称の正式名称がどこにも書かれていなかった。

## 2. 書き方

略語表は 401行。第一の出典は、運用飛行規則 Vol. A（NSTS-12820 PCN-1）の付録A「Acronyms and Abbreviations」（PDF 2161〜2192）で、326行がこれによる。付録A に無い語、付録A と意味が違う語は、各資料の本文にある「正式名称 (略称)」の形から取った。出典の欄の頁の URL が、その語の正式名称を示す頁である。正式名称は資料の綴りのままで、日本語名は本書の訳である。この書き方で載せる語は、説明書・SysML・図のラベルの全体で 10回以上、3ファイル以上に出る略称である（頻出の略称。それより少ない語は載せていない）。

## 4. 同じ略称の別の意味

同じ略称が複数の意味で使われるものがある。表では行を分けた：HSI（Horizontal Situation Indicator／Human Systems Integration）、MMU（Manned Maneuvering Unit／Mass Memory Unit）、OPS（Operational Sequences／Operations）。また、文書番号の符号が付録A の略称と同じ綴りで、意味が違うものがある：SSD（本パッケージの文書番号の接頭辞（SSD-…）。付録A の SSD（Spacecraft Software Division）とは別）、REF（機能別関連文書一覧（対象の系の文書を機能ごとにまとめた表））、OPS（運用飛行規則（NSTS-12820 Vol. A）の章別対応、ミッションフェーズ・運用モード）、PLS（ペイロード支援（PDRS・ODS）。付録A の PLS（第一着陸地）とは別）、ALS（エアロック支援系（付録A の ALS は拡張着陸地で、別））、THC（キャビン温湿度制御（付録A の THC は並進用の手動操縦桿で、別））。
