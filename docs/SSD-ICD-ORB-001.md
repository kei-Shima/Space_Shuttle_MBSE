## 1. 目的

オービタに関わる上位のインタフェース（システム間の IF-SYS 10件、オービタのサブシステムと外部要素の IF-ORB 49件）について、媒体と量、冗長の数、使う運用フェーズを、根拠の頁とともに一覧にする（上位インタフェース管理表）。IF の番号・相手・内容・上位下位は各 IF の所有文書が正であり、本書はその特性値を示す。値は乗員運用マニュアル（SCOM）・運用飛行規則・SODB の実績の運用値で、設計当初のインタフェース管理文書（ICD）の値ではない。

## 2. 表の書き方

「量」は電圧・電流・電力、圧力・流量・温度、データバスの本数・形式、周波数、荷重・結合点の数などを示す。資料に数値が無いものは「—」とした。「冗長」は独立した経路・機器の数である。「フェーズ」は SSD-OPS-PHASE-001 の PH・AB の ID で、その IF を使う期間を示す。
