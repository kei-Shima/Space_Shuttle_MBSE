## 1. 目的

機体・機器・ソフトウェア・手順の初飛行と改修を、飛行の順に記録する。これまでのモデルには、飛行ごとに付け外しするキット（SSD-VAR-ORB-001）、機体と飛行の個体（SSD-IND-ORB-001）、事故調査の勧告と改修（SSD-ACC-SYS-001）はあったが、飛行を重ねて構成がどう変わったかの時系列は無かった。本書は Mission Report 本文の「first flight of …」などの文を記録にし、機能ブロック別・年代別に集計する。

## 2. 範囲と書き方

記録は Mission Report 本文に、初飛行・初使用・改修が書かれた文で、284件（98飛行）。「first」の語が無い改修、乗員の初、ペイロード・科学実験の初飛行、記録・順位は入れていない。全数は主張しない（Mission Report にある分）。機能ブロックと種別は本書の判断で、対象の語に規則を順に当てた（拡張規則を含む。注記）。打上げ日は飛行ごとに本文の文から取り、年代別の集計に使う。
