## 1. 目的

打上げ試行（秒読み・打上げ日の設定1回）のスクラブと延期を、原因とともに記録として持つ。これまでのモデルには、秒読みの保持（SSD-GND-ORB-001）と飛行中の異常（SSD-IFA-ORB-001）はあったが、打上げに至らなかった試行と、その原因を系・天候・地上・レンジに分けた記録は無かった。本書は、Mission Report 本文に書かれた分を、飛行ごとの記録（表）と、原因の区分・機能ブロック別・飛行ごとの集計（図273〜275）にする。

## 2. 範囲と書き方

記録は Mission Report 本文の文に、スクラブ・延期とその原因が書かれているものだけで、124件（スクラブ 88・延期 36、63飛行）。表・図の OCR は読まない。Mission Report に書かれていない試行は数えていないので、打上げ試行の全数も、打上げの可用性の率も主張しない（推定の率も作らない）。スクラブは秒読み・タンキングの途中または打上げ日の当日の中止、延期は打上げ日の変更である。スクラブに伴う日付の再設定はそのスクラブの記録の一部とし、新しい理由で日付がさらに動いたときだけ延期を足した。原因の区分と機能ブロックは本書の判断で、本文が中止の直接の理由として書く語で決めた（判断の規則は注記）。

> **注記** 範囲・取れなかった値・本書の判断：135飛行のうち報告書を取り込んだのは132飛行で、そのうち記録のある飛行は63飛行である。記録のない飛行は、報告書に書かれていないか、保持・数時間の遅れだけで同じ日に打ち上げた飛行である（Mission Report に書かれていないことは、試行が無かったことを意味しない）。同じ日に保持・数時間の遅れのあと打ち上げたものは記録に入れていない（秒読みの保持の周期は SSD-GND-ORB-001）。

> **注記** 範囲・取れなかった値・本書の判断：試行の単位：1回の試行＝その飛行の打上げに向けた、秒読みまたは打上げ日の設定1回。スクラブ（秒読み・タンキングの途中または打上げ日の当日の中止）と延期（打上げ日の変更）に分ける。スクラブに伴う日付の再設定はそのスクラブの記録の一部とし、新しい理由で日付がさらに動いたときだけ延期を1件足した。

> **注記** 範囲・取れなかった値・本書の判断：原因の区分（本書の判断。優先順は 機体の系＞地上設備・地上要員＞天候＞LCC・レンジ＞ペイロード・ミッション都合＞その他）。本文が中止の直接の理由として書く語で決めた。結果を見たあとに決めた境界：乗員の体調（その他）、別の機体の打上げ（Atlas。LCC・レンジ）、流星群（その他）、地上作業の誤り（作動油の抜き取り・クローズアウトの遅れ。地上）、RMS（PLS）、貨物室の投光器（CREW）、LH2 ECO センサー（MPS）、GUCP の漏れ（ET。STS-133 の IFA の種別は I）。これらを外しても基準（原因つき30件以上・区分4つ以上・3飛行以上・機能ブロックにつながる機体の系10件以上）は成り立つ。
