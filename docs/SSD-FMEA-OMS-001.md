## 1. 目的

OMSの故障モード・影響解析（FMEA）と重要品目リスト（CIL）について、IOA（Independent Orbiter Assessment）の件数、IOA が NASA の評価と食い違いを指摘した CIL 課題の評価ワークシートと機能・IF の対応、運用飛行規則の [CIL] の規則を、根拠の頁とともに示す。系全体の冗長度の段階と重要度の定義は SSD-FMEA-ORB-001（総括・索引）に示す。

## 2. 対象と書き方

- 重要度は「ハードウェア／機能」の形（1/1、2/1R など）で、定義は SSD-FMEA-ORB-001 の「冗長度の段階と重要度」による。
- 評価ワークシートは、NASA と IOA のそれぞれについて重要度・冗長スクリーン・CIL の欄を並べ、異なる点を比較の欄に示し、IOA の勧告を記す。（出典: https://ntrs.nasa.gov/api/citations/19900001639/downloads/19900001639.pdf#page=4）
- 運用飛行規則では、CIL に関係する規則の表題に [CIL] を付け、規則の変更が CIL の存続理由に影響するときは、存続理由の変更が承認されるまで取り込まない。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=2195）

## 3. IOA の FMEA・CIL の件数

- 表1-1（1988年1月1日時点）では、軌道制御系（OMS）の FMEA は IOA 285件・NASA 243件で課題117件、CIL は IOA 140件・NASA 117件で課題60件である。（出典: https://ntrs.nasa.gov/api/citations/19900002467/downloads/19900002467.pdf#page=13）

## 6. 要約

IOA の表1-1 の1サブシステムで、CIL は IOA 140件・NASA 117件、課題は 60件である。

CIL 課題の評価ワークシートは 199件で、多い区分は 弁の電気制御（103件）・熱制御（温度センサ）（24件）・熱制御（ヒータ・温度スイッチ）（18件）である。IOA の重要度は 2/1R 83件・3/2R 54件・3/1R 30件・2/2 13件・3/3 12件・1/1 4件・空欄 2件・— 1件である。

[CIL] の規則は 5件（A6-51・A6-54・A6-61・A6-303・A6-1001）である。
