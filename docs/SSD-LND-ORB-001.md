## 1. 目的

着陸の見送り・延期・着陸地の変更を、原因とともに記録として持つ。これまでのモデルには、打上げ前のスクラブ・延期（SSD-LAV-ORB-001）と地上処理（SSD-GND-ORB-001）はあったが、帰還の側で計画の着陸の機会・日・着陸地を変えた決定と、その原因は無かった。本書は、Mission Report 本文に書かれた分を、決定ごとの記録（表）と、原因の区分・着陸地の組・飛行ごとの集計（図297〜299）にする。

## 2. 範囲と書き方

記録は Mission Report 本文の文に、着陸の決定とその原因が書かれているものだけで、137件（見送り 54・延期 40・着陸地の変更 25・機内で決めた延長 18、65飛行）。取り込んだ132飛行のうち67飛行は記録が無い（報告書に本書の定義に当たる記述が無い。着陸を早めた短縮・打上げ前の計画に入っている延長・目的が書かれない延長は定義の外）。表・図の OCR は読まない。着陸の全数も、着陸の可用性の率も主張しない（推定の率も作らない）。見送りは同じ着陸日の別の機会へ、延期は着陸日が変わった、着陸地の変更は計画と実際の着陸地が違うことで、1回の決定を1件とした。機内で決めた延長は、打上げ後に着陸日を後ろへ動かした延長のうち目的が本文にあるものを、延期の記録に加えた。原因の区分は本書の判断で、本文が直接の理由として書く語で決めた（判断の規則は注記）。
