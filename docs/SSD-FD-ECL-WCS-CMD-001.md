## 1. 目的

便器（廃棄物収集器）で糞便を搬送空気とともに疎水性の多孔質ライナに集めて貯蔵し、使わないときは真空にさらして乾燥させる機能と、使用前の加圧・スライド弁の開閉、圧縮器などの操作と故障時の扱いを示す。

## 2. 機能

| 機能番号 | 内容 |
|---|---|
| F-ECL-WCS-CMD-01 | 便器は27×27×29インチで通常のトイレと同様に使い、固形廃棄物を集めて貯蔵する多層の疎水性多孔質バッグライナを1枚持つ（SCOM 2.25節）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/755） |
| F-ECL-WCS-CMD-02 | 便器は使用中は加圧されてファンセパレータが搬送気流を作り、使わないときは減圧されて固形廃棄物を乾燥・不活性化する（SCOM 2.25節）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/755） |
| F-ECL-WCS-CMD-03 | 便と尿の収集モードでは、MODEスイッチをCOMMODE/MANUAL/EMUにしてCOMMODE CONTROLハンドルを引き上げ、デブリスクリーンと流量制限器を通したキャビン空気で約15秒で便器を加圧してから、ハンドルを前へ押してスライド弁を開く（SCOM 2.25節）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759） |
| F-ECL-WCS-CMD-04 | 糞便は直径4インチの座面開口から、座面下の穴を毎分30 ft³で流れるキャビン空気で引き込まれて多孔質ライナにたまり、空気は疎水性材を通ってファンセパレータへ向かう。疎水性材は自由な液体と細菌が収集器から出るのを防ぐ（SCOM 2.25節）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759） |
| F-ECL-WCS-CMD-05 | 紙類はすべてWCSのキャニスタバッグに入れて補助ウェットトラッシュ区画に置き、ティッシュは気流を妨げ便器のかさを増すため便器に入れないよう勧められている（SCOM 2.25節）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759） |
| F-ECL-WCS-CMD-06 | COMMODE CONTROLハンドルをBACK/DOWN位置にするとスライド弁が閉じて便器が減圧される。使用後にハンドルを完全に下げないと、真空ベント弁からキャビン空気が失われる（SCOM 2.25節）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759） |
| F-ECL-WCS-CMD-07 | 1987年の飛行運用マニュアルは、収集器の必要気流を便器で毎分30 ft³、貯蔵容積を2.4 ft³、真空ベントを通る系の漏れを最大0.0985 lb/人日とし、ゲート弁をスライド式とする。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=475） |
| F-ECL-WCS-CMD-08 | 便器の内容物は、トルクレンチ（50 in-lb）で2枚羽根の圧縮器のクランクを回して寄せ、1回目は時計回り、2回目は反時計回りに回し、網が搬送管をふさいでいないことを確かめる（Orbit Operations Checklist）。（出典: https://www.ibiblio.org/apollo/Shuttle/Orbit%20Operations%20Checklist/Orbit%20Operations%20Checklist%20Rev%20M%20PCN-10.pdf#page=404） |
| F-ECL-WCS-CMD-09 | スライド弁が開かない、便器が満杯で空にできない、糞便を保持する気流が得られない、使用時に真空ベントを外せない、糞便の貯蔵容器が破損した、のいずれかで便器を喪失とする。修理できなければ、袋の数に限りがあるため飛行を早期に終える場合がある（A17-353）。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=1985） |
| F-ECL-WCS-CMD-10 | COMMODE CONTROLハンドルには真空側と乗員室側が同時に開く可動範囲があり、ゆっくりまたは不完全に操作するとキャビン漏れを起こしうる。故障処置手順は連動機構の点検とスライド弁の清掃・点検を示す（MAL ECLS 6.2b）。（出典: https://ibiblio.org/apollo/Shuttle/Space%20Shuttle%20Malfunction%20Procedures.pdf#page=276） |
| F-ECL-WCS-CMD-11 | 便器の制御弁が故障した場合は、制御弁の連結部を点検・試験し、必要なら手で操作する（IFMチェックリストW-61）。（出典: https://www.ibiblio.org/apollo/Shuttle/In-Flight%20Maintenance/In-Flight%20Maintenance%20Checklist%20Rev%20F%20PCN-13.pdf#page=487） |
| F-ECL-WCS-CMD-12 | STS-8では、真空にさらした収集器の圧力が通常より高く、1〜2 lb/hrのキャビン漏れに相当した。スライド弁の開閉とゲート弁の清掃では直らず、就寝中は真空ベント弁を閉じて漏れを抑えた。（出典: https://www.ibiblio.org/apollo/Shuttle/Reports/Mission%20Reports/STS-8%20National%20Space%20Transportation%20Systems%20Program%20Mission%20Report.pdf#page=12） |

## 3. インタフェース

| IF番号 | 相手 | 種別 | 方向 | 内容 | 上位IF／下位IF |
|---|---|---|---|---|---|
| IF-WCS-02 | 乗員室（制御対象） | 推進薬・流体 | 受信 | 糞便を、座面下の穴から毎分30 ft³で流れるキャビン空気とともに便器へ引き込む。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759）使用前の便器の加圧も、バラスト弁と校正オリフィスを通したキャビン空気で行う。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=446） | 上位: IF-ECL-31 |
| IF-WCS-04 | ファンセパレータ・フィルタ | 推進薬・流体 | 送信 | 便器の搬送空気は疎水性の多孔質ライナを通って自由な液体と細菌を除かれ、ファンセパレータへ引かれる。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759） | — |
| IF-WCS-05 | 真空ベント | 推進薬・流体 | 送信 | WCSを使わないときは、便器（廃棄物収集器）をWCSの真空弁を通して真空ベント系にさらし、固形廃棄物を乾燥させる。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/758） | — |
| IF-WCS-14 | 制御・運用管理 | データ・指令 | 受信 | MODEスイッチをOFFから動かすまでCOMMODE CONTROLハンドルを操作できないよう、機械的に連動させる。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=474）SCOMでは、MODEスイッチをCOMMODE/MANUAL/EMUにしないとハンドルを前へ押せない。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/759） | — |

## 5. 注記（出典間の相違・構成変更）

> **注記** 検証メモ：1987年の飛行運用マニュアルは、便器に入れてよい紙はトイレ用ティッシュだけとするが、SCOM（2008年、PDF p759）はティッシュも便器に入れずWCSのキャニスタバッグへ入れるよう勧める。本書はSCOMに従った。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=447）

> **注記** 検証メモ：使用前の加圧時間を、SCOMとOrbit Operations Checklistは約15秒（15秒待つ）、1987年の飛行運用マニュアルは20秒未満（20秒待ってから開く）とする。加圧はバラスト弁と校正オリフィスを通して行う。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=446）

> **注記** 収集器と真空弁の間に0〜2 psiaの圧力トランスデューサがあり、便器の真空状態から漏れを監視する（1987年の飛行運用マニュアル）。このデータのDPSへのIFは、真空ベントのIF-WCS-12に含めた。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=439）

> **注記** 初期の便器はスリンガを持ち、STS-4では廃棄物収集器のスリンガの回転数が通常より低かった。（出典: https://www.ibiblio.org/apollo/Shuttle/Reports/Mission%20Reports/STS-4%20Orbiter%20Mission%20Report.pdf#page=43）

> **注記** EDO WCSの便器は圧縮ピストンを持ち、STS-65では3回目の圧縮でCOMMODE故障灯が点灯して圧縮ピストンが搬送管の途中で止まった。乗員が手で回して戻し、以後の圧縮は正常だった。（出典: https://www.ibiblio.org/apollo/Shuttle/Reports/Mission%20Reports/STS-65%20Space%20Shuttle%20Mission%20Report.pdf#page=33）
