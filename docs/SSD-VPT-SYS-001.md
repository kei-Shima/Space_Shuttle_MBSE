## 1. 目的

本パッケージの文書・図・モデルを、誰（関係者）のどの問い（関心事）に答えるかで整理し、ビューポイントとして定義する。SSD-SYS-ARC-001 の図 266件をそれぞれ1つのビューポイントのビューに割り当て、ビューが晒すモデルのパッケージを示す。あわせて、文書の表の ID の形（表記の規約）を定める。全体は 図111 ビューポイントと関係者の行列 に示す。

## 2. 書き方

関係者と関心事は、本パッケージの利用者と問いを ISO/IEC/IEEE 42010 の考え方で整理したもので、一次資料の記述ではない。ビューポイントは関心事を枠に入れ、SysML v2 の標準のビュー定義（GeneralView・InterconnectionView・StateTransitionView・GridView・BrowserView）を特化したビュー定義がそのビューポイントを満たす。ビューは図で、図が描くモデルのパッケージを晒す（expose）。
