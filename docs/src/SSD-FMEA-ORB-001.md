## 1. 目的

機能ブロック16件について、冗長の数と方式、運用飛行規則 A2-101 の許容段階（2故障許容・1故障許容・0故障許容）、IOA（Independent Orbiter Assessment）の FMEA・CIL の件数を、根拠の頁とともに示す。試行系として電力系（EPS）の反応剤貯蔵・分配（PRSD）の CIL 項目を、機能行（F-ID）とインタフェース（IF-ID）に対応させる。「1故障で運用継続・2故障で安全帰還」（F-ORB-03）の方針を、ブロックごとにどこまで満たすかを見る資料とし、図45 冗長度の重ね図の根拠とする。系ごとの FMEA・CIL は故障解析表 SSD-FMEA-<系>-001（16件）に示し、本書はその総括・索引とする（EPS の CIL は本書の §5〜§7 に残す）。

## 2. 冗長度の段階と重要度

| 区分 | 定義・運用（根拠） |
|---|---|
| 2故障許容 | 2故障許容（フェイルオペレーショナル／フェイルセーフ）とは、オービタの系が重要機能を完全に遂行でき、系内の任意の2故障に耐えてなお安全に軌道離脱・着陸できる状態である。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=580）シャトルは「フェイルオプス／フェイルセーフ」の思想で設計されており、任意の1構成品の喪失はミッションを損なわずに許容でき、2つ目の喪失でも機体や乗員の喪失には至らない。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/851） |
| 1故障許容 | 1故障許容（フェイルセーフ）とは、オービタの系が重要機能を完全に遂行でき、任意の1故障に耐えてなお安全に軌道離脱・着陸できる状態である。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=580）系を単一故障許容の状態に残す1故障は予定の飛行終了（NEOM）まで飛行を続けてよい構成であり、フェイルセーフを下回る単一故障では故障モードと残存能力を実時間で評価する。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=581）EVAは、PDRS（エンドエフェクタの解放、MPM収納、MRLラッチなど）の故障とペイロードベイドアの閉駆動能力の故障に対し、冗長の1段として扱われる。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=590） |
| 0故障許容 | 0故障許容（フェイルクリティカル）とは、オービタの系が重要機能を完全に遂行できるが、追加の1故障以上に耐えて安全に軌道離脱・着陸する能力がない状態である。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=580）飛行不能（アンフライアブル）とは、オービタが突入と着陸を成功させられない系の状態である。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=580）オービタの系を0故障許容の水準にする故障、またはもう1故障で重大な構成管理上の状態となる故障では、最も早い実用的な時期に米本土の着陸場へ次のPLSで軌道離脱する。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=584） |
| 規則の例 | APU／油圧系はオービタがAPU 1基での運用を認定されていないため1系統を失うとフェイルセーフでなくなるが、IMUとFCSは突入中の特定の時間帯の「スマート故障」を除き1故障後もフェイルセーフである。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=581）GPCが3台残る場合はフェイルセーフとみなされ、さらに1台が故障してもPASSのGPCが機体制御に使える。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=591）突入に重要な複数のLRUへの電力の冗長を失う単一故障では飛行を続けるが、既存の故障と重なって飛行不能となりうる単一の電気故障がある場合は次のPLSで飛行を終える。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=592） |
| 重要度（CIL） | IOA の要約は、冗長が無く乗員・機体の喪失を脅かす単一故障点を、NSTS 22206 が重要度1に分類するとしている。（出典: https://ntrs.nasa.gov/api/citations/19900002467/downloads/19900002467.pdf#page=18）IOA は、同種・異種の冗長の解釈を広くとるほど、機能の重要度 1R・2R が増えるとしている。（出典: https://ntrs.nasa.gov/api/citations/19900002467/downloads/19900002467.pdf#page=19） |

## 3. 表の書き方

冗長度の表の「段階」は A2-101 の段階で、「出どころ」の「規則」は運用飛行規則がその系をその語で述べているもの、「推定」は規則が述べる1故障後の段階から1段上と推定したもの（推定の理由は「段階」の欄の括弧内）、「受動」は冗長を持たない受動の系で、A2-101 の段階が当てはまらないものである。推定の根拠は運用飛行規則のほか、主推進系では SCOM の上昇のアボートの記述を使った。「CIL 件数」は IOA の表1-1 のCIL 項目数で、IOA の評価と NASA の基準の値を並べた。CIL の表の「重要度」は「機器／機能」の形で、R は冗長があることを示す。冗長スクリーン A・B・C の記号（P・F・NA）は IOA のワークシートのとおりである。

## 9. 要約

16ブロックの段階は、2故障許容が 3件（DPS・GNC・EPS）、1故障許容が 12件（CT・RCS・ECLSS・APU・OMS・MPS・CW・CREW・EVA・PLS・MECH・STR）、冗長なし（受動）が 1件（TPS）である。出どころは、規則 6件・推定 9件・受動 1件である。

2故障許容（1故障で運用継続・2故障で安全帰還。F-ORB-03 の方針）にあたるのは、計算機・航法・電源の3系で、いずれも推定である。1故障許容の系は1故障で0故障許容に下がるため、規則の多くは次の PLS などで帰還するとしている（各行の根拠）。

TPS と構造は IOA の28サブシステムに入っておらず、TPS は冗長を持たない受動系である。C&T・MPS・乗員系の段階は、規則に A2-101 の語での記述が無いため、各系の Go/No-Go 基準と上昇のアボートの記述から推定した（付録D の対照表は使えない。注記を参照）。

本表の 20 件の重要度は、NASA が 1/1 2件・2/1R 16件・3/1R 2件、IOA が 1/1 2件・2/1R 14件・3/1R 4件である。CIL 項目とするものは NASA 18件・IOA 16件で、両者で扱いが違うものは 6件である。対応先の多い機能・IF は F-EPS-PRSD-01（17件）・IF-EPS-03（16件）・IF-EPS-04（5件）である。重要度 1/1 の2件はタンク組立で、冗長が無い。
