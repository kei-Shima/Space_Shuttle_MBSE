## 1. 目的

廃棄物収集系（WCS）の各下位機能に関係する公開文書を機能別に整理し、各機能説明書と図23 廃棄物収集系 関連文書マトリクス（文書×機能マトリクス）の根拠とする。

## 2. 調査方法

SSD-ECLSS-REF-002の3.6節 廃棄物収集系（WCS）の10件と、同一覧の他の節からWCSの下位機能に関係する3件（A-01・A-06・B-06）の計13件を引き継ぎ（出典欄「REF-002（A-04）」の形）、今回の調査で11件を追加した（出典欄「新規」）。引き継いだ行も含め、各行の関連内容は下位機能ごとに書き分けた。SCOM、運用飛行規則、訓練マニュアル、故障処置手順（MAL）、飛行運用マニュアル（JSC-12770）、IFMチェックリスト、Orbit Operations Checklist、SODB、IOA、ミッション報告は原本で本文を確認し、関連内容に節とPDFの通し頁を示す。頁を示していない行（NTRS・SAEの抄録ページと1988年版マニュアル）は、SSD-ECLSS-REF-002と親の機能説明書に記した内容を下位機能に割り振った。
