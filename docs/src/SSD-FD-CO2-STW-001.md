## 1. 目的

予備のLiOHキャニスタ（活性炭・ATCOキャニスタを含む）の床下収納と、交換計画・予備量（レッドライン）・使用済みキャニスタの再使用・ISS係留時の分担などの管理規則を示す。

## 2. 機能

| 機能番号 | 内容 |
|---|---|
| F-CO2-STW-01 | 予備のLiOHキャニスタは最大30個を、ECLSSベイのパネルMD52Mの下に収める（訓練マニュアル3.2.2節）。（出典: https://ibiblio.org/apollo/Shuttle/Crew%20Training/Environmental%20Control%20and%20Life%20Support%20System.pdf#page=59） |
| F-CO2-STW-02 | LiOHキャニスタ区画の寸法は22.25×39.12×30.08 in、収納ラックは21×7.30×12.52 in・28 lbである（飛行運用マニュアル第12巻）。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=555） |
| F-CO2-STW-03 | キャニスタは床下の収納区画から取り出して、ファン下流の環境制御系に装着し、定期的に交換する（飛行運用マニュアル第12巻）。（出典: https://www.ibiblio.org/apollo/Shuttle/46635652-Shuttle-Flight-Operations-Manual-Vol-12-Crew-Systems.pdf#page=545） |
| F-CO2-STW-04 | LiOHキャニスタは通常、就寝前と起床後、またはPPCO2が7.6（6.1）mmHg以上と確認されたときに交換し、1個交換か2個交換かは乗員数に応じてLiOHの利用を最大にする解析で決める（A17-151C）。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=1938） |
| F-CO2-STW-05 | 就寝前と起床後のミッドデッキ作業では、それぞれ2個のうち1個のキャニスタを交換する（SCOM）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/832） |
| F-CO2-STW-06 | 打上げ前はL-5:30に始まるASPチェックリストでLiOHキャニスタを装着する（SCOM）。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/821） |
| F-CO2-STW-07 | 交換中は両方のキャビンファンを止める。キャニスタの粉塵がファンで舞い上がり、目や鼻の刺激を起こした例がある（訓練マニュアル3.2.2節）。（出典: https://ibiblio.org/apollo/Shuttle/Crew%20Training/Environmental%20Control%20and%20Life%20Support%20System.pdf#page=59） |
| F-CO2-STW-08 | ISSに備蓄したキャニスタを使うときは、LiOH粉塵への暴露を減らすため保護具を着用する（Orbit Opsチェックリスト）。（出典: https://www.ibiblio.org/apollo/Shuttle/Orbit%20Operations%20Checklist/Orbit%20Operations%20Checklist%20Rev%20M%20PCN-10.pdf#page=68） |
| F-CO2-STW-09 | 未使用のLiOHキャニスタを最低2日分予備に保持し、使用済み（袋詰め）キャニスタは能力を解析でしか評価できないためレッドラインに数えない。LiOHを使い切った後のCO2制御手段はキャビン空気の船外パージだけで、2時間程度しかもたない（A17-157）。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=1952） |
| F-CO2-STW-10 | 飛行延長で使用済みキャニスタを使う場合は、LiOHが1 lbm以上残るものだけを対象とし、なるべく早く使い、新しいキャニスタ1個と組み合わせ、PPCO2を通常7.6 mmHg未満に管理する（A17-158）。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=1953） |
| F-CO2-STW-11 | LiOHキャニスタの数と乗員数が飛行終了（EOM）の時期を決める（A17-1001注[11]）。（出典: https://archive.org/download/GandalfDDI-SpaceShuttleDocuments/Space%20Shuttle%20Operational%20Flight%20Rules%20Volume%20A%20-%20All%20Flights%2020020620%20fr_generic.pdf#page=2034） |
| F-CO2-STW-12 | STS-108では係留中にISSの装置が両機のPPCO2の大部分を管理し、交換計画より12個のLiOHキャニスタを節約したため、以後のシャトルの搭載数を減らすこととした。（出典: https://www.ibiblio.org/apollo/Shuttle/Reports/Mission%20Reports/STS-108%20Space%20Shuttle%20Mission%20Report.pdf#page=31） |

## 5. 注記（出典間の相違・構成変更）

> **注記** 検証メモ：交換中に止めるキャビンファンを、SCOM（PDF p370）は運転中のファン、訓練マニュアル（3.2.2節）は両方のキャビンファンとする。通常は1台運転のため運用上の差は小さい。本書は訓練マニュアルの記述を用いた。（出典: https://www.yumpu.com/en/document/view/40749502/390651main-shuttle-crew-operations-manual/370）

> **注記** 検証メモ：1979年の飛行運用マニュアルは、CO2分圧が5.0 mmHgに達したとき、または乗員4名ならおよそ12時間ごとにキャニスタを交換するとしていたが、運用飛行規則A17-151C（2002年）は就寝前後または7.6（6.1）mmHg以上で交換すると定める。本書は運用飛行規則の値を用いた。（出典: https://www.ibiblio.org/apollo/Shuttle/JSC-12770,%20Vol.3%20-%20Shuttle%20Flight%20Operations%20Manual,%20Environmental%20Control%20and%20Life%20Support%20Systems%20(ECLSS)%20(1979-03-03).pdf#page=35）
