## 1. 目的

シャトルの警報の区分（クラス0〜3 と補助の報知）を NASA-STD-3001 の警報の階層（表 10.3-1 の音・表 10.4-3 の色）に対応づけ、表示・操作の主な盤と乗員の作業位置、既存の警報（SSD-FDIR-ORB-001 の CW・EM）の区分を示す。照合表（SSD-HSI-SYS-001）の10章の判定の詳細に当たる（判定は変えない）。全体は図152・153 に示す。

## 2. 書き方

3001 の階層とシャトルの区分の視覚・聴覚の報知は資料の値のまま書き、対応は報知の役割（緊急・警告・注意・勧告）で本書が対応づけ、一致（報知の色・音とも同じ）・一部（一部が違う）・不一致に分けた。盤の作業位置で資料に明記の無いものは補足に「本書の判断」と書いた。

## 4. 3001 の全体の規則

警報の階層の全体に当たる 3001 の規則を示す。

| ID | 規則 | 照合表 | 根拠 |
|---|---|---|---|
| SR-01 | 同時に起きたアラートは、乗員が確認するまで最も優先度の高いものを報知し続ける。 | HSI-404 | 3001 の V2 10175 の根拠では、複数のアラートが同時に起きると、乗員が確認するまで最も優先度の高いアラートを報知し続ける。（出典: https://www.nasa.gov/wp-content/uploads/2025/05/nasa-std-3001-vol-2.pdf#page=205） |

| SR-03 | 緊急・警告・注意は見えて聞こえる二重の符号化とする。 | HSI-401・HSI-418 | 3001 の V2 10114 の根拠では、緊急・警告・注意のアラートは見えて聞こえる二重の符号化とし、勧告は音を伴っても伴わなくてもよく、音の報知に音声の警報を含められる。（出典: https://www.nasa.gov/wp-content/uploads/2025/05/nasa-std-3001-vol-2.pdf#page=204） |
